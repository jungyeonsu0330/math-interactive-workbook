# 📐 고등수학 인터랙티브 문제집 웹 애플리케이션 (Interactive Math Workbook)

대한민국 고등학교 수학 대표 교재(**유형내신 고쟁이**, **개념원리 RPM**)의 전 문항을 인터랙티브 웹 시뮬레이션 및 교과서 표준 수식(KaTeX)으로 학습할 수 있는 종합 인터랙티브 문제집 포털입니다.

---

## 📚 수록 교재 및 문항 (총 6권, 4,719문항 전수 등록)

1. **개념원리 RPM 공통수학2** (141개 쪽, **1,092문항**) ★ 신규 등록
   - 평면좌표, 직선의 방정식, 원의 방정식, 도형의 이동, 집합, 명제, 함수, 유리·무리함수
2. **개념원리 RPM 공통수학1** (137개 쪽, **1,135문항**) ★ 신규 등록
   - 다항식의 연산과 인수분해, 방정식과 부등식, 경우의 수와 행렬
3. **유형내신 고쟁이 공통수학1** (214개 쪽, **845문항**)
   - 다항식, 방정식과 부등식, 도형의 방정식
4. **유형내신 고쟁이 공통수학2** (56개 쪽, **242문항**)
   - 함수, 유리함수와 무리함수
5. **유형내신 고쟁이 대수** (175개 쪽, **670문항**)
   - 지수함수와 로그함수, 삼각함수, 수열
6. **개념원리 RPM 기하** (113개 쪽, **735문항**)
   - 이차곡선(포물선·타원·쌍곡선), 평면벡터, 공간도형과 공간좌표

## ✨ 핵심 기능

- **교과서 표준 수식 렌더링**: KaTeX 엔진을 통해 분수, 거듭제곱근, 선분, 각도, 등부등호 기호가 수학교과서 인쇄본 표준 폰트로 선명하게 출력됩니다.
- **스마트 자동 채점 및 자동 원상회복**:
  - 오답 선택 시 흔들림(Shake) 알림과 함께 1.1초 후 원래 버튼 색상으로 자동 복구되어 즉시 재도전 가능.
  - 정답 선택 시 형광 피드백 및 완료 체크 마크 갱신.
- **실시간 응용·변형 문제와 정답·풀이 100% 연동**:
  - `[원래 문제]`: 교재 원문 그대로 해결
  - `[계수 변형]`: 계수와 수치를 변형한 문항 + 변형된 수치를 대입하여 푼 단계별 정밀 풀이와 변형 정답 즉시 연동
  - `[심화 응용]`: 1등급 킬러 심화 조건이 추가된 최고난도 문제 + 심화 조건 분석 및 해설 제공
- **풍부한 개념 분해 & 조건 분석 카드**:
  - 조건 분석 (가, 나), 단원별 교과서 필수 공식, 1등급 킬러 공략법 3단계로 완벽 분석.
- **실전 직관 & 빠른 풀이 TIP**:
  - 복잡한 수식 전개 없이 기하학적 대칭성, 점근선 교점, 역함수 공식 등으로 10초 만에 푸는 시험장 꿀팁 탑재.
- **실시간 인터랙티브 Canvas 시뮬레이터**:
  - 곡선과 직선의 점을 드래그하여 교점 개수 및 기하학적 위치 관계 실시간 관찰.
- **반응형 웹 디자인**:
  - 모바일(스마트폰), 태블릿(iPad, Galaxy Tab), 데스크톱에 맞추어 유동적으로 크기가 조절되는 반응형 레이아웃.
