# 📐 고등수학 인터랙티브 문제집 웹 애플리케이션 (Interactive Math Workbook)

대한민국 고등학교 수학 교재(유형내신 고쟁이, RPM)의 전 문항을 인터랙티브 웹 시뮬레이션 및 교과서 표준 수식(KaTeX)으로 학습할 수 있는 인터랙티브 웹 애플리케이션입니다.

![Preview](gojaengi178.html)

---

## 📚 수록 교재 및 문항 (총 2,472문항 전수 등록)

1. **고쟁이 공통수학1** (본문 179개 페이지, 총 790문항)
   - 다항식, 방정식과 부등식, 도형의 방정식
2. **고쟁이 공통수학2** (함수, 유리함수, 무리수, 순열과 조합 56개 페이지, 총 242문항)
   - 135쪽~194쪽 전 문항
3. **고쟁이 대수** (본문 180개 페이지, 총 705문항)
   - 지수함수와 로그함수, 삼각함수, 수열
4. **RPM 기하** (본문 113개 페이지, 총 735문항)
   - 이차곡선(포물선, 타원, 쌍곡선), 평면벡터, 공간도형과 공간좌표

---

## ✨ 핵심 기능

- **교과서 표준 수식 렌더링**: KaTeX 및 맞춤형 정규식 복원 엔진을 통해 분수, 무리식, 거듭제곱, 선분, 각도 기호가 수학교과서 표준 폰트로 선명하게 출력됩니다.
- **실시간 인터랙티브 Canvas 시뮬레이터**:
  - 유리/무리함수 점근선 및 접선 기울기($k$) 드래그 관찰
  - 이차곡선(포물선 초점·준선, 타원·쌍곡선 초점거리) 동적 제어
  - 벡터 및 공간좌표 인터랙티브 기하 시뮬레이션
- **자동 채점 및 풀이/해설 제공**:
  - 객관식 ①~⑤ 선지 클릭 시 즉각 정답 확인 및 정오답 피드백
  - 주관식 단답형 정답 입력 및 자동 채점
  - '풀이 보기' 및 '다른 풀이' 토글
- **조건 변경 응용/변형 문제 생성**:
  - 접할 때의 기울기, 상수 조건 등을 동적으로 변경하여 유사 변형 문항 실시간 생성
- **반응형 웹 디자인 (Mobile & Tablet First)**:
  - 데스크톱뿐만 아니라 스마트폰, 태블릿(iPad, Galaxy Tab) 화면 비율에 맞춰 글씨 크기와 캔버스 크기가 `clamp()` 유동 타이포그래피로 자동 최적화됩니다.

## 🚀 로컬 실행 방법

브라우저에서 `index.html` 파일을 직접 열거나, 로컬 웹 서버(예: Live Server, Python http.server)를 통해 바로 실행할 수 있습니다.

```bash
# Python 로컬 웹 서버 실행 예시
python -m http.server 8000
```
브라우저에서 `http://localhost:8000/index.html` 로 접속합니다.
