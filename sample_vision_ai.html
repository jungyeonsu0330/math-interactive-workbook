문제 0562 고쟁이 공통수학2 · 152쪽 · 객관식 5지선다
함수 $f$에 대하여 $f^2(x) = f(f(x)), f^3(x) = f(f^2(x)), \dots$ 로 정의하자. 집합 $X = \{1, 2, 3\}$에 대하여 함수 $f : X \to X$가 두 조건 $$f(1) = 3, \quad f^3 = I \quad (I\text{는 항등함수})$$ 를 만족시킨다. 함수 $f$의 역함수를 $g$라 할 때, $g^{10}(2) + g^{11}(3)$의 값은?
【0562번 단계별 정밀 해설】 [STEP 1: 일대일대응과 f^3 = I 조건으로 f 결정] $f(1) = 3$이고 $f$는 일대일대응이다. - $f(2) = 2, f(3) = 1$이면 $f^2(1) = 1 \implies f^3(1) = 3 \neq 1$ (모순) - $f(2) = 1, f(3) = 2$이면: $f(1) = 3, f^2(1) = 2, f^3(1) = 1$ $f(2) = 1, f^2(2) = 3, f^3(2) = 2$ $f(3) = 2, f^2(3) = 1, f^3(3) = 3$ 따라서 $f^3 = I$를 만족한다. [STEP 2: 역함수 g = f^{-1}의 대응 관계] $f(1) = 3, f(2) = 1, f(3) = 2$이므로: $g(1) = 2, \; g(2) = 3, \; g(3) = 1$ 또한 $f^3 = I$이므로 $g^3 = (f^{-1})^3 = I$이다. [STEP 3: 거듭제곱의 주기성 적용] $g^{10} = g^{3 \times 3 + 1} = g$ $g^{11} = g^{3 \times 3 + 2} = g^2$ $\therefore g^{10}(2) + g^{11}(3) = g(2) + g^2(3) = g(2) + g(g(3)) = 3 + g(1) = 3 + 2 = 5$ (정답: ②)
💡 핵심 전략: 원소의 순환 주기(주기 3)를 먼저 파악한 후, 지수를 3으로 나눈 나머지로 거듭제곱을 축약합니다.
